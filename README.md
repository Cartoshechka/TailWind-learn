# UFO Styles - Outlandish Design Agency

🛸 A futuristic web design agency landing page featuring cosmic animations and out-of-this-world aesthetics.

**Learning Project** - This is a practice project created to explore modern web development techniques with Vite and TailwindCSS.

## Features

- **Responsive Design** - Optimized for all devices and screen sizes
- **Modern Tech Stack** - Built with Vite and TailwindCSS 4
- **Space Theme** - Cosmic gradients, hover effects, and UFO branding
- **Interactive Elements** - Smooth animations and transitions
- **Professional Layout** - Portfolio showcase, about section, and contact information

## Tech Stack

- **Vite** 7.0.4 - Lightning-fast build tool
- **TailwindCSS** 4.1.11 - Utility-first CSS framework
- **Autoprefixer** 10.4.21 - CSS vendor prefixing
- **Vanilla JavaScript** - Clean, modern JavaScript

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## Design Features

- **Color Scheme**: Dark theme with green (#4CAF50) and burgundy (#880E4F) accents
- **Typography**: Clean, modern sans-serif fonts
- **Animations**: Hover effects, smooth transitions, and subtle animations
- **Layout**: Mobile-first responsive design with CSS Grid and Flexbox
